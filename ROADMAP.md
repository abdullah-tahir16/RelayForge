# Roadmap

Every OpenSpec change in this repo, grouped by lifecycle state. This is a living document, not the static version-phase plan in `documentation.md` §134-139 — for the fixed v0.1–v1.0 feature scope, see that doc instead.

## Maintenance convention

This file is maintained **manually**, updated as part of running the OpenSpec workflow — not generated by a script (no build tooling exists yet to host one; see `bootstrap-monorepo-scaffolding/design.md` Decision 4).

- **Planned items** are not yet real OpenSpec changes — no `openspec/changes/<name>/` directory exists for them yet. They're a backlog, ordered by dependency.
- **`/opsx:propose`** → pick the next item from **Planned**, remove it from that list, and add it under **Proposed**.
- **`/opsx:apply`** → once a change's planning artifacts are complete and at least one task is checked, move it from **Proposed** to **Doing**. Once every task is checked, move it to **Done**.
- **`/opsx:archive`** → move the change from **Done** to **Archived**, and repoint its link at the archived location.

A change should appear in exactly one section at a time (Planned items are not "changes" yet, so they don't count against this). Treat a stale entry (wrong section, dead link) as a defect to fix, not a cosmetic issue.
